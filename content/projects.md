Some of the projects I'm working on:

* [MOS](https://mos.datatra.sh) - An assembler targeting the MOS 6502 CPU.
* [Beatlocker](https://github.com/datatrash/beatlocker) - A [Subsonic](https://www.subsonic.org/) compatible server for self-hosting your music.
* [Mashi](https://github.com/datatrash/mashi) - An experiment with [PAQ](https://mattmahoney.net/dc/)-style compression.
* [Wasm-PNG](https://github.com/datatrash/wasm-png) - A tool to create a single HTML file from your JS/WASM application.
* A new 64k intro and tooling surrounding that (editor, softsynth, etc)
* [Woolwords](https://woolwords.datatra.sh) - A cozy Android word puzzle game.
